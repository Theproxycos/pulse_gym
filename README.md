# Pulse Gym 💪

Pulse Gym is a fitness application built with Flutter and Dart, designed to support workout planning and fitness tracking through an interactive interface.

## Features

- **Workout Planning** — Organize fitness activities and workout routines.
- **Muscle Selection** — Explore muscle groups using interactive selection tools.
- **Progress Visualization** — Display fitness-related data through charts.
- **Calendar Tools** — Navigate dates and organize workout schedules.
- **Cloud Integration** — Firebase services for data storage.
- **Customizable Interface** — Adaptive themes and a responsive Flutter UI.

## Tech Stack

- Flutter & Dart
- Firebase Core
- Cloud Firestore
- Firebase Storage
- Provider
- FL Chart
- Shared Preferences

## Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK (3.5.3 or compatible)

### Installation

```bash
git clone https://github.com/Theproxycos/pulse_gym.git
cd pulse_gym
flutter pub get
flutter run
```
